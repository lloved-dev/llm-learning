## 这轮踩到的边界问题

1. **`split(' ')` 会切出空串**。文件以换行结尾，按空格切完最后一个是 `''`，`''[0]` 直接 `IndexError`。
   正确写法是不带参数的 `split()`——按任意空白切，自动丢掉空串。

2. **空文件检查失效**。`''.split(' ')` 返回 `['']`，长度是 1，所以 `len(...) == 0` 永远不成立。
   和第 1 条是同一个根因：`split(' ')` 保留了不该保留的空串。

3. **相对路径依赖当前目录**。测试里写 `"words.txt"` 在自己目录能跑，换个目录就 `FileNotFoundError`。
   改用 `Path(__file__).parent / "words.txt"`，与从哪启动无关。

4. **空文件和空字典是同一类错误**：没有数据可处理。都该在最开头 `raise ValueError`，
   在做任何计算之前拦住。

5. **求最大值的初始值不能写 0**。计数从 0 开始是合理的，分数不是——分数可以是负数。
   取「第一个元素」当初始值，两种情况下都正确。
